# Prompt: Modern & Sleek Portfolio Website for John Nwawolo

Create a **modern, sleek, responsive personal portfolio website** for a professional named **John Nwawolo**.

## Objective
Build a polished, fast-loading single-page portfolio that feels premium and contemporary, with smooth animations, clean typography, and clear sections for personal branding, projects, and contact.

## Tech Stack
- HTML5, CSS3, and vanilla JavaScript (no framework)
- Mobile-first responsive layout
- Accessible semantic markup (WCAG-friendly)

## Design Direction
- Style: minimalist, modern, elegant, and professional
- Visual language: glassmorphism/card-based sections, subtle gradients, soft shadows
- Color palette: dark primary theme with accent color (electric blue or cyan)
- Typography: clean sans-serif, strong hierarchy
- Animations: subtle fade/slide-in on scroll, hover transitions, and smooth scrolling
- Include dark/light mode toggle with localStorage persistence

## Website Structure / Tabs (Navigation)
Create a sticky top navigation with these tabs:
1. **Home**
2. **About**
3. **Skills**
4. **Projects**
5. **Experience**
6. **Testimonials**
7. **Contact**

## Section Requirements
### 1) Home
- Hero section with John Nwawolo’s name and title (e.g., “Frontend Developer & UI Enthusiast”)
- Short value proposition
- CTA buttons: “View Projects” and “Hire Me”
- Optional profile image/avatar and animated background accents

### 2) About
- Professional summary paragraph
- Quick personal highlights (location, years of experience, interests)
- Download CV button

### 3) Skills
- Grouped skill cards (Frontend, Backend, Tools, Soft Skills)
- Include progress bars or tag chips with proficiency levels

### 4) Projects
- Grid of project cards with:
  - project title
  - short description
  - tech stack tags
  - live demo link

### 5) Experience
- Vertical timeline layout for work history and education
- Role, company/school, date range, and key achievements

### 6) Testimonials
- Carousel or card layout with 3–5 testimonials
- Name, role, and short quote

### 7) Contact
- Contact form (name, email, message) with front-end validation
- Social links (LinkedIn, GitHub, X/Twitter, Email)
- Optional map/location snippet

## Functional Requirements
